Forecasts, for each of the 55 GTA VI PS5 trophies, its earn rate on Exophase at 2026-11-26T00:00:00Z. It uses an E/P growth model — earners and players-tracked are modelled separately — with refresh dilution and saturating progression, written in TypeScript (Node 22, standard library only).

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```

Run from the directory holding the `input/` cases.
